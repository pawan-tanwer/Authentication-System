# 🔐 SecureAuth

A full-stack authentication and authorization system built using the **MERN Stack**. This project demonstrates modern authentication practices including JWT authentication, Google OAuth, Email OTP verification, Role-Based Access Control (RBAC), profile management, and secure session handling.

## ✨ Features

### 🔑 Authentication
- Email & Password Registration
- Secure Login
- Google OAuth Login
- Email OTP Verification
- JWT Authentication
- Refresh Token Authentication
- HTTP-Only Cookie Authentication
- Multi Device Login

### 👤 User Features
- Profile Management
- Upload Profile Picture
- Change Password
- Change Email with OTP Verification
- View Account Information

### 🛡️ Admin Features
- User Management Dashboard
- View All Users
- Change User Roles
- Block / Unblock Users
- Role-Based Access Control (RBAC)

### 🔒 Security Features
- Password Hashing (bcrypt)
- JWT Access & Refresh Tokens
- Protected Routes
- Email Verification
- OTP Expiration
- Secure Cookies
- Input Validation
- Authentication Middleware
